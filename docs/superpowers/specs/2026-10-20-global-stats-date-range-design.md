# 统计页全局日期范围设计

## 状态

设计草案，待业主审阅。业主已确认目标：统计页顶部用统一日期选择器代替刷新按钮；选择器除预设范围外，必须允许自定义日期范围。

## 目标与验收标准

- 统计页只有一个日期范围控制，顶部固定展示当前范围，可选近 7 / 30 / 90 / 365 天，也可自定义开始日与结束日。
- 所有统计区块都使用同一范围：顶部四项指标、总体趋势、平台解析/下载、资源类型、作者解析/下载和每日热力图。
- 总体趋势与热力图不再各自维护日期状态；趋势类型、平台解析/下载、资源类型次数/字节等视图切换仍然保留。
- 起止日按本机自然日解释，开始日和结束日均包含在范围内；不能选择未来日期，开始日晚于结束日时不能应用。
- 用统计档已有记录与每日明细聚合，不能从最近历史行推算失败数或全生命周期统计。
- 统计档继续只存计数、字节与时长，不增加 URL、文件名、作者名等敏感或逐条内容。

## 数据与迁移

当前 `StatsSnapshot` 只保存总量、按日总量、平台累计桶、类型累计桶与小时桶。平台/类型桶没有日期，取消也没有日期，因此只能让趋势图响应日期选择，无法让整页真正全局筛选。

为覆盖用户要求的全部区块，主进程统计器需要将日期维度保存到统计档。建议复用本机 `YYYY-MM-DD` 日键和 366 天保留窗，为每个自然日保存：总下载成功、失败、取消、字节、解析请求与解析失败；平台解析/下载计数和字节；资源类型下载数与字节。按日期范围汇总这些桶，提供页面使用的筛选快照。总量累计桶继续保留，承担生命周期展示/兼容职责，不用于有限日期的筛选结果。

落盘 schema 需升版本并做读迁移：旧档累计总量不变，新日桶从迁移时开始累积；旧的 byDay 可迁移已有的总体字段，但旧平台和类型历史无法准确回填到日期桶。自定义选择范围中，无法回填的旧平台/类型维度应明示数据起始日或在不可覆盖的日期段显示不完整状态，不能将缺失误画成 0。日期早于可用明细的范围允许选择，但界面应提示可用统计起始日，或将日期下限限制在可用起始日；实现计划阶段需据现有 UI 空态模式定稿。

作者维度不写入 stats.json，继续从解析历史按作品去重。日期筛选按历史条目的 `createdAt` 过滤；作者数据受当前解析历史保留上限约束，超出保留范围时需要在作者区块单独表达数据覆盖范围，不能影响其他计数维度的完整性。

跨进程 `stats:get` 返回形状变化需遵守 AGENTS.md 的 IPC 六件套并升级 `CONTRACT_VERSION`。`StatsSnapshotSchema` 与磁盘 `schema` 是两个独立版本号，分别迁移/升级。继续按平台注册表归一化平台键。

## 交互与显示

- 顶部日期范围控件替换现有“刷新”按钮；刷新能力并入数据加载状态/自动加载，错误态仍可重试。
- 预设范围与自定义范围同属一个选择器。自定义模式打开日期区间面板，展示开始和结束日，并提供应用/取消；应用后一次性更新整页数据。
- 初始默认近 30 天，与当前趋势默认窗口一致。日期范围以本机日历日 inclusive 计算，今天为结束日上限。
- 范围应用后，指标卡显示范围合计；趋势和热力图连续补零；平台及资源类型排序按选中指标的范围值排序；作者行只统计所选范围内的解析/落地历史。
- 将范围标签放在页面顶部，不在每个区块重复放解释性小字。已有图表标题、切换器、空态层级保持不变。

## 不在本次范围内

- 不改 Figma 画布。
- 不改解析、下载路由或平台定义。
- 不延长现有 366 天日维度保留策略；生命周期累计数据继续保留。
- 不把作者、作品或链接维度写入统计档。

## 涉及代码面

- `types/ipc-contract.ts`：按日统计结构与返回契约。
- `types/ipc.ts`、`electron/main/ipc.ts`、`electron/preload/index.ts`、`renderer/src/lib/bridge.ts`、`renderer/src/dev/mock-bridge.ts`：如调整 stats IPC 形状，完成六件套。
- `electron/main/stats.ts` 及产生下载/解析/取消/失败事件的主进程调用点：写入每日维度并迁移旧档。
- `renderer/src/lib/stats.ts`、`renderer/src/pages/StatsPage.tsx`：日期范围聚合、统一选择器与页面数据联动。
- `renderer/src/components/ui/`：若现有控件不能满足日期区间选择，补一个轻量本地日期范围控件；避免引入新运行时依赖，除非现有依赖无法满足。
- `docs/ARCHITECTURE.md`、`docs/UIUX-DESIGN.md`：同步数据真源、留存和页面交互事实。

## 风险与待实现阶段确认的细节

1. 旧平台/类型维度无法按日拆分，迁移不能伪造精确分布；可用起始日必须在界面上清楚体现。
2. 作者使用有上限的历史明细，可能早于统计日桶起始日或缺失部分作品；作者区应显示其实际覆盖范围。
3. 当前 `cancel()` 不接收事件时间，需要在统计事件接口中带入时间戳，确保取消数按自然日归档。
4. 自定义日期区间的日历键沿用本机时区；时区变化不会迁移已落盘日键。
